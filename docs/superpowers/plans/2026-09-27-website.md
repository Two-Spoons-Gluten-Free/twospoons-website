# Two Spoons Website Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development for bounded tasks; the root coordinates integration and review.

**Goal:** Build and verify a complete pre-launch website with more than five distinct pages and functional interest capture.

**Architecture:** Astro with a standalone Node server. Render pages using shared layouts and CSS, with same-origin form APIs and private SQLite persistence. Independently create imagery, review source claims, and implement the form service while the root builds pages.

**Tech Stack:** Astro 5, TypeScript, Node 22 built-in SQLite, local Fraunces and DM Sans fonts, CSS, native browser interactions.

## Tasks
- [ ] Scaffold dependencies and scripts in `package.json`, `astro.config.mjs`, `tsconfig.json`; run `npm install`.
- [ ] Review document and verify material regulatory claims in `docs/plan-review.md`; avoid legal assertions in public copy.
- [ ] Create food imagery under `public/images/` and record provenance in `docs/image-assets.md`.
- [ ] Build `src/layouts/Layout.astro`, shared components, and `src/styles/global.css` with responsive navigation, footer, typography and shared primitives.
- [ ] Implement home, pantry, three line details, story, approach, markets, contact, signup, privacy and 404 pages under `src/pages/`.
- [ ] Implement form validation and SQLite storage in `src/lib/`, API handlers under `src/pages/api/`, and meaningful tests in `tests/`. Run tests against temporary storage. Add owner export script.
- [ ] Wire client forms to API endpoints with visible pending, success, duplicate and error states; no fake submission.
- [ ] Run `npm test` and `npm run build`. Launch `npm run dev` and exercise desktop/mobile routes, navigation, signup, contact and FAQ interactions in Playwright.
- [ ] Review content and implementation independently, fix findings, and document setup, hosting requirements and remaining business decisions in `README.md`.

## Boundaries
User has authorized the local design and build. No publishing, third-party messages, purchases, or business registrations are part of this work. The workspace starts empty and is not a Git repository, so no worktree or commit is required.
